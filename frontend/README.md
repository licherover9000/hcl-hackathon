# Frontend Application — HCL Hackathon

## 📁 Directory Structure
- `public/`: Static index.html and web assets
- `src/components/`: Modular, reusable UI components
- `src/pages/`: Main page views / dashboard routes
- `src/services/`: API clients and fetch helpers
- `src/styles/`: CSS styling files
- `src/assets/`: Images, icons, and illustrations

## 🛠️ Setup & Execution

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
```bash
cp .env.example .env
```

### 3. Run Locally
```bash
npm start
```
Runs the app in development mode on `http://localhost:3000`.
